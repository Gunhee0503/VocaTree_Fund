설정 가이드
Google 스프레드시트 연결하기
  1. 새 Google 스프레드시트 생성
    sheets.new 에서 빈 스프레드시트 생성
  2. Apps Script 열기
    메뉴 → [확장 프로그램] → [Apps Script]
  3. 스크립트 코드 붙여넣기
    기본 코드를 모두 지우고, 아래 [📋 코드 복사] 버튼으로 복사한 코드를 붙여넣기 후 저장(Ctrl+S)
  4. 웹 앱으로 배포
    우측 상단 [배포] → [새 배포] → 톱니바퀴 → [웹 앱] 선택
    • 다음 사용자로 실행: 본인(나)
    • 액세스 권한: 모든 사용자 ← 중요!
    [배포] 클릭 후 권한 승인
  5. 웹 앱 URL 복사 → 위 [Apps Script 웹앱 URL] 칸에 붙여넣기 → 저장
    URL 형식: https://script.google.com/macros/s/.../exec
  6. 학생들에게 이 어휘테스트 HTML 파일 공유
    학생들은 별도 설정 없이 바로 응시 가능 (URL은 자동 적용)
✅ 설정 완료!
